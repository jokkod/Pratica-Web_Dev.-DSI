## 💻 Instalação e Execução

1. Clone este repositório:
   ```bash
   git clone https://github.com/jokkod/Pratica-Web_Dev.-DSI.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Abra o projeto em seu navegador:
   ```bash
   http://localhost:5173
   ```
